## 페이지별 상세

### p1 — 로그인 (Login / 환영합니다)
- **목적**: 기존 계정 로그인, 관리 시스템 진입.
- **대상**: 전체(public, 미인증).
- **레이아웃**: 셸-A 좌우 2분할(히어로 + 폼).
- **컴포넌트**: 헤딩 "환영합니다", 이메일 input(메일 아이콘, placeholder `name@company.com`), 비밀번호 input(자물쇠 아이콘 + 눈 토글) + "비밀번호 찾기" 링크, "로그인 상태 유지" 체크박스, 프라이머리 버튼 "로그인"(다크), 구분선, 하단 "회원 가입" 링크("관리자 승인을 요청하세요" = 가입 후 admin approve 플로우 암시).
- **백엔드 매핑**: `auth/login`. 하단 카피가 admin accounts approve/reject 게이트를 반영.

### p2 — 회원가입: 소매(Retailer) (Sign-up / 회원가입)
- **목적**: 비즈니스 계정 생성, 회원 유형 선택.
- **대상**: public(가입자).
- **레이아웃**: 셸-A. 우측 세로 폼.
- **컴포넌트**: 세그먼트 컨트롤(탭 3개) **Member Type** = Retailer(소매, 선택=다크) / Wholesaler(도매) / Agency(에이전시). 인풋: Full Name(성명), Company Name(회사명), Business Email, Password, Confirm Password. 프라이머리 버튼 "Create Account (계정 생성)". 하단 "Log In (로그인)" 링크.
- **백엔드 매핑**: `auth/register` + `seller_type` 분기.

### p3 — 회원가입: 도매(Wholesaler) (Sign-up Wholesaler / 계정 생성)
- **목적**: 도매 파트너 가입 — 사업자 인증 서류 첨부.
- **대상**: wholesaler.
- **레이아웃**: 셸-A. 폼이 더 김(서류 업로드 포함).
- **컴포넌트**: Member Type 세그먼트(Wholesaler 선택=다크). 2열 인풋(성명/회사명, 비밀번호/비밀번호 확인), 이메일 단일 인풋. **비즈니스 인증** 섹션: 카드형 파일 업로드 2개 — "사업자등록증"(JPG/PNG/PDF, MAX 5MB, "파일 선택" 버튼) + "신분증"(주민등록증/운전면허증). 약관 동의 체크박스, 프라이머리 버튼 "계정 생성 →".
- **백엔드 매핑**: `auth/register`(wholesaler) + 인증서류 업로드(추가 필요). admin approve 대상.

### p4 — 회원가입: 에이전시(Agency) (Sign-up Agency / 계정 생성)
- **목적**: 에이전시 파트너 가입(p3와 동일 폼, 라벨만 에이전시).
- **대상**: agency. (※ CLAUDE.md: 에이전시 실운영 미구현 — forward-compat).
- **레이아웃**: 셸-A. p3와 동일.
- **컴포넌트**: Member Type(Agency 선택=다크), 동일 인풋·서류 업로드 카드·약관 체크박스·"계정 생성 →". placeholder만 `agencypro@example.com`, 회사명 "(주) 에이전시 프로".

### p5 — POS 주문 화면 (POS / 상품 그리드 + 주문 패널)
- **목적**: 현장 POS — 상품 선택해 주문 담기 + 결제 진행.
- **대상**: wholesaler / 매장 직원.
- **레이아웃**: 좌(상품 그리드 70%) + 우(고정 주문 사이드패널 30%).
- **컴포넌트**:
  - 상단 검색바("상품명 또는 SKU 검색…").
  - 카테고리 세그먼트(pill): 전체 상품(선택) / 상의(TOPS) / 하의(BOTTOMS) / 아우터(OUTERWEAR) / 액세서리(ACCESSORIES).
  - **상품 카드 그리드**(4열): 상품 사진 + 재고 배지("IN STOCK"=흰/검, "LOW STOCK"=흰/검 좌상단), SKU(예 LS-BL-01), 상품명, 가격(₩).
  - 빈 카드 "커스텀 상품 추가"(점선 드롭존 + ⊕).
  - 우측 **주문 내역 패널**: "현재 주문 내역" 헤더 + 비우기 아이콘, 라인아이템(썸네일·이름·단가·수량 스텝퍼 −/+·합계), 액션 3버튼(할인 적용 %, 주문 보류 ⏸, 고객 선택 👤+), 소계/부가세(VAT 10%)/총 결제 금액, 프라이머리 "결제하기 (Checkout)".
- **백엔드 매핑**: products 조회 + (주문/결제 = Phase 2). 카탈로그 가격 셰이핑 연계.

### p6 — 결제 모달 (Checkout Modal / 결제하기)
- **목적**: 결제 수단 선택 + 영수증/정보노출 옵션 후 결제 완료.
- **대상**: wholesaler.
- **레이아웃**: 중앙 모달(딤드 배경 = p5 위에 오버레이), 모달 내부 좌우 2분할.
- **컴포넌트**: 모달 헤더 "결제하기 (Checkout)" + X 닫기. 좌측 = 주문 내역 테이블(품목/수량/금액) + 공급가액/부가세/총 결제 금액(대형). 우측 = **결제 수단** 카드 4개(카드/현금/계좌이체/포인트, 각 아이콘), "영수증 출력" 토글 체크박스(체크됨), **정보 노출 설정** 박스(눈-가림 아이콘) — "가격 정보 숨기기 / 제품 상세 정보 숨기기" 체크박스(주석: 에이전시 소속 셀러 등 가격 노출 민감 시). 하단 버튼: "취소 (Cancel)"(아웃라인) / "결제 완료 (Complete)"(다크).
- **백엔드 매핑**: 가격 노출 숨김 옵션 = `price_visibility` 정책과 직결.

### p7 — 커스텀 상품 추가 모달 (Custom Product Entry / 커스텀 상품 추가)
- **목적**: 카탈로그에 없는 상품을 즉석 입력해 주문에 추가.
- **대상**: wholesaler.
- **레이아웃**: 중앙 모달(p5 위 오버레이).
- **컴포넌트**: 헤더 "커스텀 상품 추가 / CUSTOM PRODUCT ENTRY" + X. 인풋: 상품명, 품번(Product ID/SKU). 카테고리 세그먼트(커스텀=선택/일반/특별). 2열: 도매가/소매가(₩). 색상/사이즈. 혼용률(예 면 100%)/재고(스텝퍼). 상세설명(textarea). 하단 "취소"(아웃라인)/"추가하기 🛒"(다크).
- **백엔드 매핑**: products create(단건). 도매가/소매가 동시 입력.

### p8 — 대시보드 (Dashboard / 개요)
- **목적**: 도매 운영 실시간 분석·메트릭 개요.
- **대상**: admin / wholesaler 매니저.
- **레이아웃**: 셸-B. 콘텐츠 = 히어로 배너 + KPI 4카드 + 차트 2×2.
- **컴포넌트**:
  - 히어로 배너(쇼룸 사진 위 어둡게 + "개요 / 홀세일 프로 실시간 분석 및 메트릭스").
  - **KPI 카드 4개**: 일간 매출 ₩1.6억(▲+8.2% 초록), 신규 주문 342(▲+12.4% 초록), 활성 고객 1,890(▼-1.2% 빨강), 재고 상태 94%(─ 안정 회색). 각 우상단 아이콘.
  - **컬렉션 퍼포먼스** 라인 차트 + 세그먼트(일간 선택/주간/월간), x축 월~일.
  - **고객별 주문** 바 차트(C1~C7, C6 강조=검정) + … 메뉴.
  - **상품 분석** 도넛 차트(45% 탑 티어, 범례 45/30/25%) + "베스트셀러 vs 품절예상".
  - **라이브 커머스 전환율** 퍼널(총 시청자 125,000 → 상품 클릭 45,200(36%) → 장바구니 18,500(14.8%) → 주문 완료 8,250(6.6%)), 각 진행바 + 필터 아이콘.
- **백엔드 매핑**: 분석 집계(신규/미구현). 라이브커머스 셀러 타깃 반영.
