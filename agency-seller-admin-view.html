3지금은 안 보임 · 백엔드는 준비됨

1차엔 에이전시 가입이 막혀 있어 실제 화면엔 아직 “에이전시 소속”이 안 뜹니다. 켜지는 순간 자동 노출.

지금 (1차)
전부 라이브셀러
에이전시 자가가입 비활성 → 가입 셀러는 모두 independent. 화면엔 회색 “라이브셀러”만.
→
가입 복구 시
agency_affiliated 셀러 생성
에이전시 운영 시작 → agency_id 가 채워진 소속 셀러가 가입.
→
자동
배지 자동 표시
서버가 agency_id→name 보강 → 에이전시 소속 + 이름이 그대로 뜸. 코드 수정 0.
