한눈에 이해하기

말로 풀면

🏢도매업체 ≠ 에이전시

둘은 다른 주체라 표를 나눴습니다. wholesalers는 상품을 파는 쪽, agencies는 셀러를 관리하는 쪽. 그래서 products.wholesaler_id는 도매업체만 가리킬 수 있습니다(타입 안전).

👤사람은 어디 소속?

로그인 계정은 profiles. 도매 직원은 wholesaler_id, 에이전시 직원·에이전시 소속 셀러는 agency_id로 소속을 가리킵니다.

📦업체 → 상품

도매업체 하나가 상품(products)을 여럿 올립니다. 품번 충돌은 글로벌 platform_code로 차단.

🎨상품 → 옵션·이미지

상품 하나엔 색상/사이즈별 product_skus(도매가·판매가·재고)와 product_images가 여러 개 매달립니다.

🔍누가 어떤 가격을 보나

보여줄 가격은 profiles.price_visibility(관리자 설정)로 결정 — 미설정이면 셀러 유형 기본값. 라이브셀러→도매가, 에이전시→판매가, 소속셀러→미노출.

📥엑셀 대량 업로드

엑셀 한 번 올리면 upload_jobs가 파싱·매칭 상태를 추적하고, 누락 건은 수작업 매칭으로 넘깁니다.
