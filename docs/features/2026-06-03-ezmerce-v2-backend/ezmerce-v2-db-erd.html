한눈에 이해하기

말로 풀면

🏢조직과 사람

organizations가 도매업체·에이전시. 실제 로그인 계정은 profiles이고, 각 계정이 어느 조직 소속인지 organization_id로 연결됩니다.

📦업체 → 상품

도매업체 하나가 상품(products)을 여럿 올립니다. 품번 충돌은 글로벌 platform_code로 막습니다.

🎨상품 → 옵션·이미지

상품 하나엔 색상/사이즈별 product_skus(도매가·판매가·재고)와 product_images가 여러 개 매달립니다.

🔍누가 어떤 가격을 보나

가격은 SKU에 2종(도매가/판매가). 보여줄 가격은 profiles.price_visibility(관리자 설정)로 결정 — 미설정이면 셀러 유형 기본값.

📥엑셀 대량 업로드

엑셀 한 번 올리면 upload_jobs가 파싱·매칭 진행상태를 추적하고, 누락 건은 수작업 매칭으로 넘깁니다.

🔐인증

profiles.id는 Supabase의 auth.users와 1:1. 로그인은 Supabase Auth가, 역할·권한은 profiles가 맡습니다.
