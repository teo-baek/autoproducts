6 테이블 — 충돌 없는 품번, 분리된 가격

사용자가 처음 요청한 "백엔드 DB구조"의 결과물. 마스터/옵션/이미지/잡을 분리하고, 품번은 글로벌 platform_code + 업체 스코프 원본품번으로 이중 차단합니다.

organizations
  • iduuid
  • name · typewholesaler|agency
profiles
  • id → auth.usersuuid
  • role · status4역할/승인
  • seller_type소속/개인
  • organization_idfk
products
  • iduuid
  • platform_codeUNIQUE 글로벌
  • source_p_number업체 원본
  • statusactive|archived
  • wholesaler_org_idfk
product_skus
  • iduuid
  • color · size옵션
  • wholesale_price도매가
  • retail_price판매가
  • stock재고
product_images
  • iduuid
  • match_statusmatched|unmatched
  • original_filename매칭키
upload_jobs
  • iduuid
  • status파싱 단계
  • error_detailjsonb
organizations 1→* profiles · organizations(wholesaler) 1→* products 1→* skus / images
