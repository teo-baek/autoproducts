# 요구사항: ezmerce v2 백엔드 (1차 — 상품·권한 코어)

> **다음 단계 안내**: 이 문서는 PRD (기획 단계 요구사항만) 입니다. 다음 단계로 `tech-design` skill (또는 `/tech-design` 슬래시) 을 호출해서 `ezmerce-v2-backend-tech-design.md` (기술 설계서) 를 만드세요. DB 스키마/테이블 설계, 인증 방식(Supabase Auth), RLS 정책, API 명세 등 **기술 결정은 여기 박지 말고** 다음 단계에 넣습니다.

## 1. 배경/목적

**제품**: ezmerce — *폐쇄형(Closed) B2B 도매 카탈로그 및 주문 관리 솔루션*
**고객**: LALAS(동대문 도매상인연합)
**마일스톤**: LALAS LIVE DDP 쇼룸 라이브 일정에 맞춘 **PoC를 방송 2~3일 전 배포**가 1차 데드라인.

동대문 도매상은 비정형 엑셀 + 수기 라벨로 상품/거래처를 관리한다. 라이브커머스 셀러는 도매 카탈로그를 받아 방송·판매하지만, 가격/품번/이미지 정보가 업체마다 제각각이라 매칭·공유 리소스가 크다. ezmerce는 **사전 승인된 사용자(도매업체·소매셀러·에이전시)만 접근하는 폐쇄형 환경**에서, 도매 상품을 한 번 등록하면 ① 표준화된 카탈로그로 셀러에게 공유되고 ② QR/엑셀로 오프라인 출력까지 연결되는 **데이터 통합 + 권한 제어 기반 시스템**을 만든다.

**1차(본 PRD)의 목적**: 향후 영업·도입의 기반이 되는 **코어 엔진** — (1) 상품 데이터 업로드/관리, (2) QR·엑셀 출력 자동화, (3) 역할 기반 폐쇄형 카탈로그 + 가격 차등 노출 — 을 완성한다.

## 2. 사용자 스토리 / 시나리오

- **도소매 관리자(Admin)**로서, 도매업체·소매셀러·에이전시의 가입을 **승인/거절/삭제**하여 폐쇄형 네트워크를 관리하고 싶다. (관리자 계정은 에이전시 또는 LALAS 연합 리더에게 제공)
- **도매업체(Wholesaler)**로서, 기존 POS에서 뽑은 상품 데이터를 **표준 엑셀 템플릿 + 이미지로 대량 업로드**하고, 등록된 상품을 수정/삭제/보관하고 싶다.
- **도매업체**로서, 등록 상품을 **QR이 박힌 엑셀로 출력**해서 별도 폼텍 라벨 작업 없이 오프라인에 쓰고 싶다.
- **소매 셀러(라이브커머스 셀러)**로서, 로그인하면 **승인된 나에게만 열린 카탈로그**에서 상품을 보고, 내 계약 조건에 맞는 **도매가**를 확인하고, 셀러용 엑셀로 받고 싶다.
- **에이전시(Agency)**로서, 카탈로그에서 **판매가**를 기준으로 상품을 보고 싶다. *(1차에는 에이전시 실제 운영은 하지 않으나 역할/권한 구조는 준비)*
- **소비자/현장 스태프**로서, 상품 **QR을 스캔하면 인스타그램 비율의 모바일 카드**로 제품 정보를 보고 싶다.

## 3. 기능 요구사항 (FR)

### FR-1. 계정·역할 (RBAC) 및 폐쇄형 접근
- **FR-1.1**: 4개 역할로 계정을 분리하고 역할별 권한을 제어한다 — `도소매 관리자(Admin)`, `도매업체(Wholesaler)`, `소매 셀러(Retail Seller, =라이브커머스 셀러)`, `에이전시(Agency)`.
- **FR-1.2**: 소매 셀러는 하위 유형을 가진다 — `에이전시 소속 셀러` / `개인 셀러`. (가격 노출 규칙의 기준이 됨)
- **FR-1.3**: 사전 승인된 계정만 시스템에 접근할 수 있다. 관리자가 가입 요청을 **승인/거절/삭제**한다. 미승인·비로그인 사용자는 카탈로그에 접근할 수 없다.
- **FR-1.4**: 사용자는 로그인/인증을 거쳐야 하며, 모든 데이터 접근·가격 노출은 인증된 역할을 기준으로 서버에서 결정된다.

### FR-2. 상품 등록 및 관리 (CRUD)
- **FR-2.1**: 도매업체는 상품을 **단건 등록**할 수 있다. 항목: 품번, 상품명, 색상/사이즈 등 옵션, 도매가/판매가, 소재(혼용률), 원산지, 작업기간, 설명, 대표 이미지, 품절 여부.
- **FR-2.2**: 도매업체는 **표준 엑셀 템플릿**으로 상품을 **대량 등록(Bulk)**하고, 상품 **이미지를 대량 업로드**할 수 있다.
- **FR-2.3**: 업로드 시 엑셀 행 ↔ 이미지 파일을 **품번/이미지명 기준으로 자동 매칭**하고, 매칭 실패·누락 건은 **사용자가 수작업으로 매칭하는 보조 인터페이스**를 제공한다.
- **FR-2.4**: 등록된 상품을 **수정/삭제/보관(Archive)** 할 수 있다.
- **FR-2.5**: **품번 정규화** — 여러 도매업체의 상품이 섞여도 충돌하지 않도록, 플랫폼이 상품에 **자체 식별자**를 부여한다. (업체별 원본 품번은 함께 보존)

### FR-3. 엑셀 출력
- **FR-3.1**: 셀러/도매업체가 상품 정보를 **지정된 엑셀 포맷으로 다운로드**할 수 있다.
- **FR-3.2**: 엑셀 다운로드 시 **최우측 열에 상품별 QR 코드가 이미지로 자동 삽입**된다. (별도 폼텍 라벨 출력 과정 대체)

### FR-4. QR 코드
- **FR-4.1**: 상품 등록 시 **상품별 개별 QR 코드가 자동 생성**된다.
- **FR-4.2**: QR 스캔 시 **인스타그램 비율의 모바일 카드 형태 제품 정보 페이지**가 노출된다.

### FR-5. 폐쇄형 권한 카탈로그 뷰 + 가격 차등 노출
- **FR-5.1**: 사전 승인된 **소매 셀러·에이전시만 접근 가능한 전체 상품 카탈로그 뷰**를 제공한다.
- **FR-5.2**: 역할/유형에 따라 가격을 **차등 노출**한다 (서버에서 결정, 클라이언트 신뢰 금지):
  | 역할/유형 | 노출 가격 |
  |---|---|
  | 계약된 소매 셀러(라이브셀러) — 개인 셀러 | **도매가** |
  | 에이전시 | **판매가** |
  | 에이전시 소속 셀러 | **가격 미노출** (제품 정보만) |
  | 미승인 / 비로그인 | 접근 불가 |
- **FR-5.3**: 카탈로그에서 FR-3의 셀러용 엑셀(QR 포함) 다운로드로 연결된다.

## 4. 비기능 요구사항 (NFR)

- **NFR-1 (데이터 정합성)**: 품번 충돌이 발생하지 않아야 한다. 상품 마스터와 옵션(색상/사이즈)·가격·재고를 분리해 옵션 단위로 관리한다.
- **NFR-2 (보안/폐쇄성)**: 가격 노출은 반드시 **서버 측에서 역할 기준으로 결정**한다. 미승인/비로그인 접근은 차단한다.
- **NFR-3 (성능)**: 카탈로그 조회는 **페이지네이션**으로 처리하고, 대량 업로드는 수백 건 규모를 한 번에 처리할 수 있어야 한다. *(구체 수치는 tech-design에서 확정)*
- **NFR-4 (배포 가능성)**: PoC는 **라이브 방송 2~3일 전 배포** 가능한 수준으로 범위를 통제한다.

## 5. 범위 밖 (Out of Scope) — 1차 제외

- 주문/발주 자동 라우팅 (Phase 2)
- 배송 현황 실시간 동기화 대시보드 / 그리드형 통합 관리 UI (Phase 2)
- 정산·미송 원장(Ledger) 시스템 (후순위)
- 구독 결제·PG 연동 (Phase 3, 미정)
- 통합 채팅 라우팅 / AI 에이전트 (Phase 3, 미정)
- 초대 전용(Invite Token) 기능 (후순위)
- **비정형 엑셀 자동 파싱** (1차는 표준 템플릿만, 자동 파싱은 다음 단계)
- **일반(비라이브) 소매업체 대상** (1차는 라이브커머스 셀러만)
- **에이전시 실제 운영** (역할/권한/데이터 모델만 준비, 당장 운영 X)
- 의미 검색 / 다국어 AI 검색 (v1 비전, 1차 제외)

## 6. 수용 기준 (Acceptance Criteria)

- **AC-1**: 도매업체가 표준 엑셀 템플릿 + 이미지를 업로드하면, 상품이 옵션(색상/사이즈)·도매가/판매가와 함께 등록되고 **품번 충돌이 발생하지 않는다**.
- **AC-2**: 엑셀↔이미지 매칭 실패 건이 있을 때 **수작업 매칭 UI로 보정**한 뒤 정상 등록된다.
- **AC-3**: 등록된 모든 상품에 **QR이 자동 생성**되고, 스캔 시 모바일 카드 페이지가 열린다.
- **AC-4**: 엑셀 다운로드 시 **최우측 열에 QR 이미지가 삽입**되어 받아진다.
- **AC-5**: 라이브셀러(개인)로 로그인 → 카탈로그에서 **도매가**가 보인다 / 에이전시로 로그인 → **판매가**가 보인다 / 에이전시 소속 셀러 → **가격이 보이지 않는다**.
- **AC-6**: **미승인 계정은 카탈로그에 접근할 수 없다**. 관리자가 승인하면 접근 가능해진다.
