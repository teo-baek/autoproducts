1

관리자 로그인 + 두 메뉴 확인

웹 로그인 → 관리자 콘솔(/admin)

위 박스의 rythmn@naver.com / lalas2026! 로 로그인합니다. 관리자 콘솔로 들어가집니다.

기대 결과
  • 왼쪽 메뉴에 「가입 승인」 과 「상품 관리」 두 개가 보임
  • 상단에 Admin 표시

실패 시: 로그인이 안 되면 비밀번호가 lalas2026! 인지 다시 확인(느낌표 포함).

2

도매관리자 — 합산 상품 관리 (핵심 신기능)

관리자 콘솔 → 상품 관리

「상품 관리」 메뉴를 누릅니다. 소속 도매업체 전체의 상품이 한 화면에 합쳐져 나옵니다.

기대 결과
  • 「도매 출처」 열에 각 상품이 어느 도매업체 것인지 이름이 보임
  • 도매가와 판매가가 둘 다 보임(관리자라서)
  • 검색창(상품명·품번), 상태 탭(전체/판매중/보관), 아래쪽 페이지 이동이 동작

상품이 0개로 보이면: 0단계 마이그레이션의 backfill이 안 됐을 수 있음 → 0단계 확인 SQL 다시 점검.

3

가입 승인 흐름

관리자 콘솔 → 가입 승인

새 도매 또는 셀러 계정으로 회원가입을 하나 만들어 두고(다른 브라우저/시크릿창), 관리자 콘솔의 「가입 승인」 → 승인 대기 탭에서 그 계정을 승인 합니다.

기대 결과
  • 가입한 계정이 승인 대기 목록에 뜸
  • 도매를 승인하면 → 도매업체가 자동 생성되고 LALAS에 연결 → 그 도매의 상품이 2단계 「상품 관리」에 합산되어 나타남
  • 셀러를 승인하면 → 그 셀러가 로그인 시 카탈로그를 볼 수 있게 됨(4단계)
4

단일 도매업체 화면 — 자기 상품만

도매 계정으로 로그인 → 상품관리(/products)

관리자에서 로그아웃하고, 도매 계정으로 로그인합니다(도매 작업공간).

기대 결과
  • 상품관리에 자기 도매업체 상품만 보임(다른 도매 상품이 섞이지 않음)
  • 관리자 콘솔(가입승인/합산 상품관리)에는 못 들어감 — 도매는 자기 화면으로

다른 도매 상품이 섞여 보이면 알려주세요(분리 실패 신호).

5

셀러 카탈로그/쇼룸 + 역할별 가격

셀러 계정으로 로그인 → 쇼룸

셀러 계정으로 로그인해 쇼룸(카탈로그)을 봅니다. LALAS 소속 도매들의 상품이 보여야 합니다.

기대 결과 — 셀러 유형별 가격 노출
셀러 유형가격 표시
일반(라이브) 셀러 — independent도매가 노출
에이전시 소속 셀러 — agency_affiliated가격 문의(미노출)

중요: 미노출 셀러에게 가격이 0원이나 빈칸이 아니라 「가격 문의」로 보여야 정상입니다.

6

공개 QR 카드

QR 스캔 또는 /p?code=… 링크

상품의 공개 QR 카드 링크를 엽니다(엑셀의 QR 또는 /p?code=EZM-…).

기대 결과
  • 비로그인 상태: 상품 정보만, 가격·재고 없음
  • 셀러 로그인 상태: 역할별 가격/재고가 추가로 보임(5단계 규칙과 동일)
7

회귀 확인 — 예전과 똑같이 보이는지

셀러 쇼룸 / 카탈로그 엑셀

이번 작업은 1차엔 결과가 예전과 똑같아야 정상입니다(LALAS 하나뿐이라 빠지는 상품이 없어야 함). 둘째 도매관리자가 생기는 먼 미래에야 화면이 갈라집니다.

기대 결과
  • 셀러 쇼룸/카탈로그에 보이는 상품 개수가 재편 전과 동일
  • 카탈로그 엑셀 다운로드도 예전과 동일하게 나옴(가격 규칙 그대로)

상품이 줄었거나 비었으면 0단계 backfill 누락 가능성 — 알려주세요.
